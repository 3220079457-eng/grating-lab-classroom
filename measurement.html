测定色散曲线与光栅常数

  1. 调整分光计。先调目镜看清叉丝，再用平面镜自准直，使望远镜适合观察平行光，光轴垂直于分光计转轴。调整平行光管，使狭缝像清晰、无视差，两光轴平行。
  2. 放置并调平光栅。把光栅放在载物台中心，按本机调平螺钉的布置区分两个调节方向。教材图 6-39 的放置方法便于分别调节光栅面的倾斜和刻线方向。先利用反射的小十字像调光栅面，再转动望远镜比较零级两侧谱线的高度。按图 6-40 微调至左右等高，使刻线平行转轴，然后复查反射像。
  3. 建立正入射。望远镜叉丝对准零级并固定，转动载物台，使光栅反射回来的十字像与自准直标志重合。固定载物台，再松开望远镜测谱线。各螺钉编号以现场机型为准。
  4. 读零级，再读左右两侧。先记零级两游标位置。对蓝、绿、黄一、黄二逐条测量 −1、+1 及 −2、+2 级的位置；每次对准同一条谱线都读Ⅰ、Ⅱ两个游标。以零级为基准，若同色同级两侧偏角明显不对称，复查正入射与级次。
  5. 求角度并作图。每个游标先求左右夹角的一半，再平均。用每行 φ 和已知 λ 求 dᵢ，在同一坐标系绘制一级和二级 φ–λ 曲线。

测定分辨本领与角色散率

用刻度尺沿垂直刻线方向测受照宽度 L，结合平均光栅常数估算 N 和 R。在一级观察黄双线，逐渐遮住部分光栅，记录谱线宽度和可辨程度的变化。保持入口狭缝宽度不变，以便考察受照刻线数的影响。再从两条色散曲线分别求黄双线附近的斜率，与理论值比较。

比较光栅光谱与棱镜光谱

两者都能把汞灯的复色光展开成谱线。光栅靠多束光干涉产生多个级次；从零级向同一侧观察，长波长偏角较大。普通玻璃棱镜在可见光正常色散区靠折射率的波长依赖分光，短波长通常偏折更多，谱线间距随波长的变化也不同。请结合实际看到的排列与疏密作答。

注意事项

拿取光栅时夹持边缘，避免触摸刻线或镀膜。汞灯使用配套限流电源和防护灯罩，禁止将灯管直接接入市电。汞灯发出紫外辐射，请勿直视裸灯。

课前自问：怎样保证公式的条件？

使用 d sin φ = kλ 前，应确认平行光正入射、刻线平行转轴，并在零级两侧识别出同一波长和同一级次。尝试向同伴说明：哪些条件靠自准直核验，哪些要通过左右谱线等高、角位置对称来复查？

数据处理一　独立算一组

选择一行，分别求出两个游标的左右半夹角，取平均得到 φ，再求光栅常数 d。

需要计算提示左右读数跨零时取较小夹角。每个游标的夹角除以二，再将两者平均。d = |k|λ / sin φ，注意计算器的角度模式。

数据处理二　一级和二级色散曲线

横轴为波长，纵轴为衍射角。比较同一级的两个点，可用 Δφ / Δλ 估计这一波段的平均角色散率。

光栅常数、角色散率与分辨本领

以有效行求 d̄。对每一级黄双线，以 Δφ/Δλ 求实验斜率（角度转弧度），以该级两黄线的平均角和 d̄ 求 k/(d̄ cos φ)。L 从 mm 换算为 nm 后再除以 d̄。

怎样区分角色散率与分辨本领？角色散率描述谱线中心的角距离随波长变化的快慢。理想光栅的分辨本领 R = |k|N，其中 N 为实际受照刻线数。狭缝过宽会使谱线展宽，即使中心分开也可能难以辨认。
